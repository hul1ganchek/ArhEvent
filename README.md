# ArhEvent 
An Android application for informing residents of the Arkhangelsk region about incidents.

This repository contains the source code for the ArhEvent mobile client, developed as a course project.

## Features
- instantly fetches and processes emergency updates from regional open sources;
- caches the incident feed into a local database, allowing users to read previously loaded emergency news even without an active internet connection;
- аllows users to categorize notifications by type (critical emergencies or planned utility/road maintenance);
- priority levels for alerts, ensuring critical life-safety threats always break through, while minor updates remain silent;
- includes user-defined background sync intervals to balance real-time awareness with mobile data and battery saving.

## Usage
Clone the repo and build it in Android Studio, or download the `.apk` from Releases.
Permissions: 
- allow on first launch to filter incidents by your district;
- enable notifications in settings.
